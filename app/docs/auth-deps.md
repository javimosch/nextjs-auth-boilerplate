# Authentication Dependencies

This document lists the npm packages required for implementing authentication in the application.

## Required Packages

1. **@supabase/auth-helpers-nextjs**
   - **Description**: Provides helper functions for integrating Supabase authentication with Next.js applications.
   - **Installation**: 
     ```bash
     npm install @supabase/auth-helpers-nextjs
     ```

2. **@supabase/supabase-js**
   - **Description**: The official JavaScript client for Supabase, used for interacting with the Supabase API.
   - **Installation**: 
     ```bash
     npm install @supabase/supabase-js
     ```

3. **next**
   - **Description**: The React framework for building server-side rendered applications.
   - **Installation**: 
     ```bash
     npm install next
     ```

4. **react**
   - **Description**: A JavaScript library for building user interfaces.
   - **Installation**: 
     ```bash
     npm install react
     ```

5. **react-dom**
   - **Description**: Provides DOM-specific methods that can be used at the top level of your app.
   - **Installation**: 
     ```bash
     npm install react-dom
     ```

## Optional Packages

1. **resend**
   - **Description**: A package for sending emails, used for password reset functionality.
   - **Installation**: 
     ```bash
     npm install resend
     ```

## Conclusion

These packages are essential for implementing authentication features in the application, including user registration, login, and account management.
